# soc-python

Learning Python by building small tools for SOC analyst work.

## Lessons

| Lesson | File | What it does |
| --- | --- | --- |
| 1 | `lesson1.py` | Counts failed SSH logins in `auth.log` |

## Running

Python 3 is required. From this folder:

```
python3 lesson1.py
```

## Sample data

`auth.log` is a made-up SSH log for practice. The IP addresses are from ranges reserved for documentation, so they do not belong to real hosts.
